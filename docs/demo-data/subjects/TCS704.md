## Course outcomes

- **CO1** — Discuss the classes of computers, and new trends and developments in computer architecture.
- **CO2** — Study advanced performance enhancement techniques such as pipelines, dynamic scheduling branch predictions, caches.
- **CO3** — Compare and contrast the modern computer architectures such as RISC, Scalar, and multi-CPU systems.
- **CO4** — Critically evaluate the performance of different CPU architecture.
- **CO5** — Improve the performance of applications running on different CPU architectures.
- **CO6** — Develop applications for high performance computing systems

### Q1

**Numerical · 3 marks · medium · Apply · CO4 · Unit 1: “Amdahl's Law”**

An enhancement speeds up 80% of a program's execution time by a factor of 10. What is the overall speed-up? (Two decimal places.)


**Answer:** 3.57 (± 0.01)

**Model answer:** S = 1 / (0.2 + 0.8 / 10) = 1 / 0.28 = 3.57.

### Q2

**MCQ · 1 mark · easy · Understand · CO1, CO3 · Unit 1: “Classification of parallel computers”**

In Flynn's classification, a processor that applies the same instruction to many data elements at once (as a GPU does) is:

- (A) SISD
- (B) SIMD
- (C) MISD
- (D) MIMD

**Answer:** (B) SIMD

**Model answer:** Single instruction, multiple data.

### Q3

**Numerical · 2 marks · easy · Apply · CO4 · Unit 1: “Measuring Performance”**

A program executes 2 x 10^9 instructions with an average CPI of 1.5 on a 3 GHz processor. What is its CPU time in seconds?


**Answer:** 1 (± 0.001)

**Model answer:** CPU time = IC x CPI / clock rate = 2e9 x 1.5 / 3e9 = 1.0 s.

### Q4

**Short Answer · 3 marks · medium · Understand · CO4 · Unit 1: “Benchmark Standards”**

Why are standard benchmark suites such as SPEC used to compare processors, and why are their results summarised with the geometric mean of speed ratios?


**Model answer:** Suites of real programs give a representative, reproducible workload that vendors cannot tune for a single kernel. The geometric mean of ratios to a reference machine gives the same ranking whichever machine is the reference.

### Q5

**Numerical · 2 marks · medium · Apply · CO2 · Unit 2: “Cache memory organizations”**

A 32 KB, 4-way set-associative cache has 64-byte blocks. How many bits of the address are used as the set index?


**Answer:** 7

**Model answer:** Sets = 32768 / (64 x 4) = 128 = 2^7, so 7 index bits.

### Q6

**Numerical · 3 marks · hard · Apply · CO2, CO5 · Unit 2: “Advanced Optimization of Cache Performance”**

L1 hit time is 1 ns with a 5% miss rate; L2 hit time is 10 ns with a 20% local miss rate; main memory takes 100 ns. What is the average memory access time in ns?


**Answer:** 2.5 (± 0.01)

**Model answer:** AMAT = 1 + 0.05 x (10 + 0.2 x 100) = 1 + 0.05 x 30 = 2.5 ns.

### Q7

**Short Answer · 4 marks · medium · Understand · CO2, CO3 · Unit 2: “Cache Coherence and Synchronization Mechanism”**

Explain how a snooping write-invalidate protocol (such as MSI) keeps caches coherent when two processors read and then one writes the same block.


**Model answer:** Both caches hold the block in Shared state after reading. The writer broadcasts an invalidate on the bus; the other copy becomes Invalid and the writer's copy Modified. A later read by the other processor misses, the owner supplies or writes back the data, and both return to Shared.

### Q8

**MCQ · 1 mark · easy · Remember · CO2 · Unit 2: “Virtual Memory”**

What does the translation lookaside buffer (TLB) cache?

- (A) Recently used data blocks
- (B) Recently used virtual-to-physical page translations
- (C) Branch target addresses
- (D) Disk sectors

**Answer:** (B) Recently used virtual-to-physical page translations

**Model answer:** The TLB is a cache of page table entries.

### Q9

**True/False · 1 mark · easy · Understand · CO1 · Unit 2: “Virtual Machines”**

True or False: A virtual machine monitor (hypervisor) lets several operating systems share one physical machine while keeping them isolated from one another.


**Answer:** True

**Model answer:** True; the VMM virtualises the hardware for each guest and isolates them.

### Q10

**Numerical · 3 marks · medium · Apply · CO2, CO4 · Unit 3: “Linear pipeline processor”**

A linear pipeline has 4 stages of equal delay. What is its speed-up over a non-pipelined unit when processing 100 tasks? (Two decimal places.)


**Answer:** 3.88 (± 0.01)

**Model answer:** S = n k / (k + n - 1) = 100 x 4 / 103 = 3.88 (approaching k = 4 for large n).

### Q11

**Short Answer · 4 marks · medium · Understand · CO2 · Unit 3: “Dynamic instruction scheduling”**

Explain how Tomasulo's algorithm uses reservation stations and register renaming to allow out-of-order execution.


**Model answer:** Instructions are issued to reservation stations that hold operands or tags of the producing units; renaming to station tags removes WAR and WAW hazards. Instructions execute when operands are ready, and results are broadcast on the common data bus to waiting stations and registers.

### Q12

**Short Answer · 4 marks · medium · Analyze · CO2 · Unit 3: “branch prediction”**

A loop branch is taken 9 times and then not taken once, and the loop runs repeatedly. Compare the mispredictions per loop execution of a 1-bit predictor and a 2-bit saturating-counter predictor, in steady state.


**Model answer:** 1-bit: mispredicts at the exit (predicts taken) and again at the first iteration of the next run (predicts not taken): 2 per run. 2-bit: one not-taken outcome only weakens the prediction, so it mispredicts only at the exit: 1 per run.

### Q13

**Assertion-Reason · 2 marks · medium · Analyze · CO2 · Unit 3: “Pipeline Hazards”**

Read the assertion and reason about pipeline hazards and choose the correct option.

- **Assertion (A):** A structural hazard occurs when two instructions need the same hardware resource in the same clock cycle.
- **Reason (R):** Separate instruction and data memories can remove some structural hazards.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (B) Both A and R are true, but R is not the correct explanation of A

**Model answer:** Both statements are true, but R describes a remedy rather than explaining what a structural hazard is.

### Q14

**Short Answer · 5 marks · medium · Apply · CO5 · Unit 4: “Basic Compiler techniques for exploiting ILP”**

Explain how loop unrolling combined with instruction scheduling increases instruction-level parallelism, and state two costs of unrolling.


**Model answer:** Unrolling replicates the loop body, removing branch and counter overhead and exposing independent instructions that the compiler can reorder to hide latencies (using different registers). Costs: larger code (instruction-cache pressure) and more registers needed; leftover iterations need extra code.

### Q15

**MCQ · 1 mark · easy · Understand · CO2 · Unit 4: “Reducing the branch penalty with advanced branch predictions”**

What does a branch target buffer (BTB) store?

- (A) The outcome of every past branch in the program
- (B) The predicted target addresses of recently executed branch instructions
- (C) The return addresses of procedure calls only
- (D) The contents of the instruction cache

**Answer:** (B) The predicted target addresses of recently executed branch instructions

**Model answer:** A BTB maps branch instruction addresses to predicted targets so fetch can continue without waiting for decode.

### Q16

**Fill in the Blank · 2 marks · easy · Remember · CO2 · Unit 4: “overcoming data hazards with dynamic scheduling”**

Register renaming removes the name-dependence hazards ___ and ___, but it cannot remove true data dependences (RAW).


**Answer:** blank 1: WAR; blank 2: WAW

**Model answer:** WAR (anti-dependence) and WAW (output dependence).

### Q17

**Case Study · 10 marks · hard · Evaluate · CO3, CO4 · Unit 4: “exploiting ILP using multiple issues”**

> **Case:** A company designs two processors: (1) a low-power digital signal processor for audio equipment that runs a few fixed, highly regular filtering kernels compiled once, and (2) a laptop processor that must run unmodified commercial software from many vendors at good performance.

Evaluate superscalar and VLIW multiple-issue designs for each product in the case and recommend one for each, with justification.


**Model answer:** (1) VLIW: the compiler schedules regular loops statically, so hardware is simpler and lower power; binary compatibility is not needed. (2) Superscalar with dynamic scheduling: hardware finds parallelism at run time in arbitrary code and keeps compatibility with existing binaries, at the cost of power and complexity.

### Q18

**Short Answer · 4 marks · medium · Analyze · CO3 · Unit 5: “Message passing vs Shared Memory”**

Compare message-passing and shared-memory multiprocessors in terms of programming model, communication cost and scalability.


**Model answer:** Shared memory: one address space, communication by loads and stores, easier programming but needs coherence and synchronisation; scaling is limited by the interconnect. Message passing: private memories, explicit send/receive, harder to program but scales to thousands of nodes because no global coherence is required.

### Q19

**Long Answer · 8 marks · hard · Create · CO5, CO6 · Unit 5: “Centralized shared-memory”**

Design a multithreaded approach to multiply two 4096 x 4096 matrices on a 16-core centralized shared-memory machine. Describe the data partitioning, synchronisation, cache-friendly loop order and the factors that limit the speed-up.


**Model answer:** Partition result rows (or blocks) among 16 threads, so no two threads write the same element and no locks are needed; join at the end. Use blocked (tiled) multiplication with i-k-j order for spatial locality and reuse in cache. Limits: memory bandwidth, false sharing on boundary cache lines, load imbalance and thread start-up overhead (Amdahl's serial part).

### Q20

**Short Answer · 3 marks · easy · Understand · CO3 · Unit 5: “Vector Architectures”**

What are vector registers and vector chaining, and why do vector architectures suit scientific loops?


**Model answer:** Vector registers hold many elements and one instruction operates on all of them; chaining forwards results of one vector unit element by element into the next. Scientific loops apply the same operation to long arrays, so few instructions do much work with deep pipelining.
