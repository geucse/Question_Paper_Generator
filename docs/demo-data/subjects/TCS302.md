## Course outcomes

- **CO1** — Describe the concept of Data Structures and assess how the choice of data structures impacts the performance of programs
- **CO2** — Compare and contrast merits and demerits of various data structures in terms of time and memory complexity.
- **CO3** — Identify and propose appropriate data structure for providing the solution to the real world problems.
- **CO4** — Implement operations like searching, insertion, deletion, traversing mechanism etc. on various data structures
- **CO5** — Be familiar with advanced data structures such as balanced search trees, hash tables, AVL trees, priority queues, ADT etc.
- **CO6** — To augment merits of particular data structures on other data structure to develop innovation in subject of study.

### Q1

**Short Answer · 3 marks · easy · Understand · CO1 · Unit 1: “Algorithm Complexity and Time-Space trade-off”**

Explain the time-space trade-off with one example from data structures.


**Model answer:** Using more memory can reduce running time and vice versa. Example: a hash table uses extra space to give average O(1) search instead of O(n) linear search; a lookup table of precomputed values trades memory for speed.

### Q2

**Short Answer · 4 marks · medium · Apply · CO4 · Unit 1: “Conversion of Infix to Prefix and Postfix Expressions”**

Convert the infix expression A + B * (C - D) / E to postfix using a stack, showing the stack contents after each symbol.


**Model answer:** Postfix: A B C D - * E / +. Operators are pushed by precedence; '(' is pushed, ')' pops to '('; '*' and '/' (left-associative) pop each other before '+' is popped at the end.

### Q3

**Numerical · 2 marks · easy · Apply · CO4 · Unit 1: “Evaluation of postfix expression using stack”**

Evaluate the postfix expression 6 2 3 + - 3 8 2 / + * using a stack.


**Answer:** 7

**Model answer:** 2 3 + = 5; 6 5 - = 1; 8 2 / = 4; 3 4 + = 7; 1 7 * = 7.

### Q4

**Numerical · 2 marks · medium · Apply · CO1 · Unit 1: “Tower of Hanoi Problem”**

How many disk moves does the recursive solution of the Tower of Hanoi make for 7 disks?


**Answer:** 127

**Model answer:** T(n) = 2T(n-1) + 1 = 2^n - 1; for n = 7, 2^7 - 1 = 127.

### Q5

**Short Answer · 4 marks · medium · Analyze · CO2, CO3 · Unit 1: “Sparse Matrices”**

A 1000 x 1000 matrix of integers has only 2000 non-zero entries. Compare the memory needed by a 2D array and by a triplet (row, column, value) representation, assuming 4-byte integers, and state which you would use.


**Model answer:** 2D array: 10^6 x 4 = 4,000,000 bytes. Triplets: 2000 x 3 x 4 = 24,000 bytes (plus a header row). The triplet form uses about 0.6% of the memory, so it is preferred for sparse data.

### Q6

**MCQ · 1 mark · easy · Understand · CO1 · Unit 2: “Circular queue”**

In an array-based circular queue of size N that keeps one slot empty, which condition indicates the queue is full?

- (A) front == rear
- (B) (rear + 1) % N == front
- (C) rear == N - 1
- (D) front == 0

**Answer:** (B) (rear + 1) % N == front

**Model answer:** With one slot left empty, the queue is full when advancing rear would reach front: (rear + 1) % N == front.

### Q7

**Programming · 6 marks · medium · Apply · CO4 · Unit 2: “Insertion and deletion to/from Linked Lists”**

Write a C function that deletes the first node with a given key from a singly linked list and returns the (possibly new) head. Handle the empty list and deletion of the head node.

*Language:* C

**Model answer:**

```c
struct node *delete_key(struct node *head, int key) {
    struct node *prev = NULL, *cur = head;
    while (cur && cur->data != key) { prev = cur; cur = cur->next; }
    if (!cur) return head;            /* not found or empty */
    if (!prev) head = cur->next;      /* deleting the head */
    else prev->next = cur->next;
    free(cur);
    return head;
}
```

### Q8

**Assertion-Reason · 2 marks · medium · Analyze · CO2 · Unit 2: “Doubly linked list”**

Read the assertion and reason about doubly linked list and choose the correct option.

- **Assertion (A):** Given a pointer to a node, deleting that node takes O(1) time in a doubly linked list.
- **Reason (R):** Each node of a doubly linked list stores a pointer to its predecessor as well as its successor.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (A) Both A and R are true, and R is the correct explanation of A

**Model answer:** Both true and R explains A: the predecessor is reachable directly, so no traversal is needed.

### Q9

**Short Answer · 5 marks · hard · Evaluate · CO3, CO5 · Unit 2: “Priority Queue”**

A hospital triage system must always serve the most critical patient first while patients keep arriving. Evaluate a sorted linked list and a binary heap as implementations of this priority queue and recommend one.


**Model answer:** Sorted list: insert O(n), remove-max O(1). Binary heap: insert and remove-max O(log n). With frequent arrivals and removals the heap's O(log n) for both operations is better overall, so recommend the heap.

### Q10

**Short Answer · 4 marks · medium · Apply · CO4 · Unit 3: “Traversing Binary trees”**

The preorder traversal of a binary tree is A B D E C F and its inorder traversal is D B E A F C. Construct the tree and give its postorder traversal.


**Model answer:** Root A; left subtree from inorder D B E (root B, children D and E); right subtree F C (root C, left child F). Postorder: D E B F C A.

### Q11

**Numerical · 5 marks · hard · Apply · CO5 · Unit 3: “Huffman algorithm & Huffman tree”**

Build a Huffman tree for symbols with frequencies a:5, b:9, c:12, d:13, e:16, f:45. What is the total number of bits needed to encode a message with exactly these frequencies?


**Answer:** 224

**Model answer:** Code lengths: f 1, c 3, d 3, e 3, a 4, b 4. Bits = 45x1 + 12x3 + 13x3 + 16x3 + 5x4 + 9x4 = 45 + 36 + 39 + 48 + 20 + 36 = 224.

### Q12

**MCQ · 1 mark · easy · Understand · CO2 · Unit 3: “binary search”**

What is the maximum number of comparisons binary search needs to find a key in a sorted array of 1000 elements?

- (A) 10
- (B) 500
- (C) 100
- (D) 1000

**Answer:** (A) 10

**Model answer:** ceil(log2(1001)) = 10 comparisons in the worst case.

### Q13

**Long Answer · 8 marks · medium · Analyze · CO2, CO5 · Unit 3: “Collision Resolution Strategies”**

Insert the keys 23, 43, 13, 27 into a hash table of size 10 using h(k) = k mod 10 with (a) linear probing and (b) separate chaining. Show both tables and compare the two strategies for clustering and memory use.


**Model answer:** h: 23->3, 43->3, 13->3, 27->7. Linear probing: 23 at 3, 43 at 4, 13 at 5, 27 at 7 (primary clustering at 3-5). Chaining: slot 3 holds 23 -> 43 -> 13, slot 7 holds 27. Chaining avoids clustering but needs extra pointer memory; probing stores keys in the table but degrades as load factor rises.

### Q14

**Short Answer · 4 marks · medium · Analyze · CO2 · Unit 4: “Quick Sort”**

Explain why quick sort with the first element as pivot takes O(n^2) time on an already sorted array, and suggest a pivot strategy that avoids it.


**Model answer:** Each partition splits off only the pivot, giving partitions of size n-1, n-2, ...: n(n-1)/2 comparisons. Choosing a random pivot or median-of-three gives balanced partitions on average, O(n log n).

### Q15

**True/False · 1 mark · easy · Understand · CO2 · Unit 4: “Two Way Merge Sort”**

True or False: Two-way merge sort takes O(n log n) time in the best, average and worst cases.


**Answer:** True

**Model answer:** True: it always splits in halves (log n levels) and merges n elements per level.

### Q16

**Long Answer · 8 marks · hard · Apply · CO5 · Unit 4: “AVL Trees”**

Insert the keys 30, 20, 10, 25, 28, 40 one by one into an empty AVL tree. Show the tree after each insertion and name each rotation performed.


**Model answer:** 30,20,10: LL imbalance at 30 -> right rotation, root 20 (10, 30). 25: under 30's left. 28: LR imbalance at 30 -> left rotation at 25 then right rotation at 30, giving 28 with children 25 and 30. 40: right child of 30, which makes the root 20 unbalanced (left height 1, right height 3, RR case) -> left rotation at 20. Final: 28 with left subtree 20 (10, 25) and right subtree 30 (-, 40).

### Q17

**Fill in the Blank · 2 marks · easy · Remember · CO4 · Unit 4: “Heap Sort”**

Heap sort first builds a ___ heap in O(n) time and then repeatedly swaps the root with the last element, giving an overall worst-case time of ___.


**Answer:** blank 1: max; blank 2: O(n log n)

**Model answer:** A max-heap is built, then n extract steps of O(log n): O(n log n).

### Q18

**Short Answer · 4 marks · medium · Understand · CO5 · Unit 5: “B+ Tree index Files”**

Explain why B+ tree index files are preferred over B tree index files for range queries on a database file.


**Model answer:** In a B+ tree all records (or pointers) are in the leaves, which are linked in key order; a range query finds the first key and scans the leaf chain. In a B tree keys are spread over internal nodes, requiring tree traversal for a range.

### Q19

**Short Answer · 4 marks · medium · Apply · CO4 · Unit 5: “Traversal(DFS,BFS)”**

A graph has vertices 1-6 and edges 1-2, 1-3, 2-4, 2-5, 3-5, 5-6, with adjacency lists in increasing order. Give the BFS and DFS orders starting from vertex 1 and name the data structure each traversal uses.


**Model answer:** BFS (queue): 1 2 3 4 5 6. DFS (stack/recursion): 1 2 4 5 3 6. BFS visits level by level; DFS goes deep along 1-2-4, backtracks to 5, then 3 and 6.

### Q20

**Case Study · 10 marks · hard · Create · CO3, CO6 · Unit 5: “Minimum spanning tree”**

> **Case:** A campus must connect five buildings A, B, C, D and E with fibre. Cable costs (in lakh rupees) are: A-B 4, A-C 3, B-C 1, B-D 2, C-D 4, C-E 5, D-E 6. Every building must be reachable and the total cost must be minimum.

Model the case as a weighted graph, find a minimum spanning tree with Kruskal's or Prim's algorithm, and state its total cost. Explain which data structures make your chosen algorithm efficient.


**Model answer:** Kruskal: B-C 1, B-D 2, A-C 3, then C-E 5 (A-B 4 and C-D 4 form cycles). MST cost = 1 + 2 + 3 + 5 = 11 lakh. Kruskal uses sorting plus a union-find (disjoint set) structure; Prim uses a priority queue (heap).
