## Course outcomes

- **CO1** — Understand Software Development Life Cycle and importance of engineering the software.
- **CO2** — Development of efficient software requirement specification for desired product.
- **CO3** — Compare various software development methodologies ad conclude on their applicability in developing specific type of product.
- **CO4** — Construct an efficient design specification document for attainment of user desired product.
- **CO5** — Develop applications using the concepts of various phases of software development life cycle.
- **CO6** — Study various software testing techniques and identify their relevance to developing a quality software.

### Q1

**True/False · 1 mark · easy · Understand · CO1 · Unit 1: “Software Myths”**

True or False: Adding more programmers to a software project that is already late will reliably make it finish sooner.


**Answer:** False

**Model answer:** False. New people need training and add communication paths (Brooks' law), which usually delays a late project further.

### Q2

**Short Answer · 4 marks · medium · Understand · CO3 · Unit 1: “The Spiral Model”**

Why is the spiral model called risk-driven? Describe the four activities of each loop of the spiral.


**Model answer:** Each loop starts by identifying and resolving the main risks before committing further. Activities: determine objectives and constraints; identify and resolve risks (e.g. prototypes); develop and verify the next-level product; plan the next iteration with customer review.

### Q3

**Assertion-Reason · 2 marks · medium · Understand · CO3 · Unit 1: “Agile Development Process”**

Read the assertion and reason about the agile development process and choose the correct option.

- **Assertion (A):** Agile methods deliver working software in short iterations and adapt to changing requirements.
- **Reason (R):** Agile methods value comprehensive documentation over working software.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (C) A is true, but R is false

**Model answer:** A is true; R is false: the Agile Manifesto values working software over comprehensive documentation.

### Q4

**Case Study · 10 marks · hard · Evaluate · CO3 · Unit 1: “Critical Comparisons of SDLC models”**

> **Case:** (1) Payroll software for a firm with stable, well-understood rules and a fixed deadline. (2) A first-of-its-kind student mental-health app whose users cannot describe their needs precisely. (3) A large defence communication system with high technical risk and a multi-year budget.

Recommend a software development life-cycle model for each project in the case and justify each choice against the alternatives.


**Model answer:** (1) Waterfall (or incremental): requirements are stable and well documented. (2) Prototyping or agile: user feedback on early versions clarifies needs. (3) Spiral: explicit risk analysis each cycle suits high-risk, large, long projects. Waterfall would be risky for (2) and (3); spiral is too heavy for (1).

### Q5

**MCQ · 1 mark · easy · Understand · CO2 · Unit 2: “Functional and Non- functional requirements”**

Which of the following is a non-functional requirement for an online examination portal?

- (A) The system shall let a teacher submit a question for review
- (B) The system shall generate a question paper from a blueprint
- (C) The system shall respond to 95% of requests within 2 seconds
- (D) The system shall let a reviewer approve a question

**Answer:** (C) The system shall respond to 95% of requests within 2 seconds

**Model answer:** Response time is a performance (quality) requirement; the others describe functions.

### Q6

**Short Answer · 4 marks · medium · Apply · CO2 · Unit 2: “Decision Table”**

A library allows borrowing if the member has no overdue books and has fewer than 5 books issued; a member with overdue books is fined, and a member who already has 5 books is told the limit is reached. Draw a decision table with conditions, actions and rules.


**Model answer:** Conditions: C1 overdue books? C2 books issued < 5? Rules: (N, Y) -> issue book; (N, N) -> limit reached; (Y, Y) -> fine, do not issue; (Y, N) -> fine and limit reached, do not issue.

### Q7

**Short Answer · 5 marks · medium · Apply · CO2, CO4 · Unit 2: “Structured Analysis: DFD, Data Dictionary”**

Draw (describe) the context-level (level 0) DFD for a library management system and give two data dictionary entries for its data flows.


**Model answer:** One process 'Library Management System'; external entities Member, Librarian; flows: borrow request, return details, issue slip, fine notice, reports. Data dictionary: borrow request = member_id + book_id + date; issue slip = member_id + book_id + due_date.

### Q8

**Long Answer · 6 marks · medium · Create · CO2 · Unit 2: “The software requirements document and SRS standards”**

Prepare the outline of an SRS document, following the IEEE 830 structure, for a hostel room-allocation system, with one example requirement in each requirements section.


**Model answer:** 1 Introduction (purpose, scope, definitions, references, overview); 2 Overall description (product perspective, functions, user classes, constraints, assumptions); 3 Specific requirements: functional (e.g. 'The system shall allocate a room by merit rank'), external interfaces, performance ('allocation results within 5 s'), design constraints, attributes (security: only wardens edit allocations).

### Q9

**MCQ · 1 mark · easy · Remember · CO4 · Unit 3: “Coupling, Cohesion”**

Which combination characterises a good modular design?

- (A) High coupling and high cohesion
- (B) Low coupling and high cohesion
- (C) High coupling and low cohesion
- (D) Low coupling and low cohesion

**Answer:** (B) Low coupling and high cohesion

**Model answer:** Modules should be independent (low coupling) and focused (high cohesion).

### Q10

**Numerical · 2 marks · medium · Apply · CO4, CO6 · Unit 3: “Cyclomatic Complexity Measures: Control Flow Graphs”**

A function's control flow graph has 9 edges and 7 nodes and is a single connected component. What is its cyclomatic complexity?


**Answer:** 4

**Model answer:** V(G) = E - N + 2 = 9 - 7 + 2 = 4: four independent paths to test.

### Q11

**Numerical · 4 marks · hard · Apply · CO4 · Unit 3: “Function Point (FP) Based Measures”**

A system has 5 external inputs, 4 external outputs, 3 external inquiries, 2 internal logical files and 1 external interface file, all of average complexity (weights 4, 5, 4, 10, 7). The 14 general system characteristics total 42. Compute the function points.


**Answer:** 84.53 (± 0.05)

**Model answer:** UFP = 20 + 20 + 12 + 20 + 7 = 79; VAF = 0.65 + 0.01 x 42 = 1.07; FP = 79 x 1.07 = 84.53.

### Q12

**Short Answer · 4 marks · medium · Understand · CO4 · Unit 3: “Design Patterns”**

State the intent of the Singleton and Observer design patterns and give one situation in an exam portal where each would be appropriate.


**Model answer:** Singleton: exactly one instance with a global access point (e.g. the configuration or connection-pool manager). Observer: dependents are notified when a subject changes (e.g. notify reviewers when a question is submitted).

### Q13

**Short Answer · 4 marks · medium · Analyze · CO6 · Unit 4: “Structural Testing (White Box Testing)”**

Compare white-box and black-box testing in terms of what they are based on, who typically performs them, and the kinds of defects each is better at finding.


**Model answer:** White-box is based on code structure (statement, branch, path coverage), done by developers; finds untested paths and logic errors. Black-box is based on specifications (equivalence classes, boundaries), done by testers; finds missing or incorrect functions and interface errors.

### Q14

**MCQ · 1 mark · easy · Remember · CO6 · Unit 4: “Test Drivers and Test Stubs”**

In top-down integration testing, lower-level modules that are not yet developed are replaced by:

- (A) Test drivers
- (B) Test stubs
- (C) Test oracles
- (D) Mock users

**Answer:** (B) Test stubs

**Model answer:** Stubs stand in for called modules; drivers stand in for callers (bottom-up).

### Q15

**Short Answer · 4 marks · medium · Apply · CO6 · Unit 4: “Functional Testing (Black Box Testing)”**

An applicant's age must be from 18 to 60 inclusive. Design test cases using equivalence partitioning and boundary value analysis.


**Model answer:** Partitions: below 18 (invalid), 18-60 (valid), above 60 (invalid): e.g. 10, 35, 70. Boundaries: 17, 18, 19, 59, 60, 61.

### Q16

**True/False · 1 mark · easy · Understand · CO6 · Unit 4: “Regression Testing”**

True or False: Regression testing re-runs previously passed tests after a change to check that existing functionality still works.


**Answer:** True

**Model answer:** True; it guards against new defects introduced by changes.

### Q17

**Numerical · 3 marks · medium · Apply · CO5 · Unit 5: “Constructive Cost Models (COCOMO)”**

Using basic COCOMO for an organic project (E = 2.4 x KLOC^1.05 person-months), estimate the effort for a 32 KLOC project. Give two decimal places.


**Answer:** 91.33 (± 0.1)

**Model answer:** E = 2.4 x 32^1.05 = 2.4 x 38.05 = 91.33 person-months.

### Q18

**MCQ · 1 mark · easy · Understand · CO5 · Unit 5: “Categories of Maintenance”**

Changing a released system to fix a defect reported by its users is which category of maintenance?

- (A) Corrective
- (B) Perfective
- (C) Preventive
- (D) Adaptive

**Answer:** (A) Corrective

**Model answer:** Fixing reported faults is corrective maintenance.

### Q19

**Short Answer · 5 marks · hard · Evaluate · CO5 · Unit 5: “Software Risk Analysis and Management”**

Risk R1 has probability 0.3 and would cost Rs 5 lakh; risk R2 has probability 0.6 and would cost Rs 2 lakh. Compute each risk exposure, decide which to address first, and propose one mitigation for it.


**Model answer:** RE = probability x loss: R1 = 1.5 lakh, R2 = 1.2 lakh. Address R1 first (higher exposure). Mitigation depends on the risk, e.g. for a key-staff loss risk: cross-training and documentation; monitor both risks.

### Q20

**Short Answer · 3 marks · easy · Remember · CO5 · Unit 5: “SEI-CMM Model”**

List the five maturity levels of the SEI Capability Maturity Model in order.


**Model answer:** Initial, Repeatable, Defined, Managed, Optimizing.
