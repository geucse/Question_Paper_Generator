## Course outcomes

- **CO1** — Understand various asymptotic notations to analyze time and space complexity of algorithms.
- **CO2** — Analyze the various paradigms for designing efficient algorithms using concepts of design and conquer, greedy and dynamic programming techniques.
- **CO3** — Provide solutions to complex problems using the concept of back tracking and branch and bound techniques.
- **CO4** — Apply algorithm design techniques to predict the complexity of certain NP complete problems.
- **CO5** — Implement Dijkstra’s, Bellman-ford, Prims, Kruskal’s algorithms to solve the real world problems like traveling salesman problem, job sequencing, packet routing etc
- **CO6** — Apply pattern matching algorithms like Rabin Karp Algorithm, Brute-force techniques etc to find a particular pattern.

### Q1

**Short Answer · 3 marks · medium · Apply · CO1 · Unit 1: “Master theorem”**

Use the master theorem to solve T(n) = 4T(n/2) + n^2, stating which case applies.


**Model answer:** a = 4, b = 2, n^(log_b a) = n^2 = f(n): case 2, so T(n) = Theta(n^2 log n).

### Q2

**True/False · 1 mark · easy · Understand · CO1 · Unit 1: “Asymptotic Notations”**

True or False: If f(n) = 3n^2 + 10 n log n, then f(n) = O(n^2).


**Answer:** True

**Model answer:** True: n log n grows slower than n^2, so f(n) <= 13 n^2 for n >= 1.

### Q3

**Numerical · 3 marks · medium · Analyze · CO1 · Unit 1: “Fibonacci and solving its recursion”**

The naive recursive function fib(n) returns n for n <= 1 and fib(n-1) + fib(n-2) otherwise. How many calls to fib (including the first) are made to compute fib(5)?


**Answer:** 15

**Model answer:** C(n) = C(n-1) + C(n-2) + 1 with C(0) = C(1) = 1: C(2) = 3, C(3) = 5, C(4) = 9, C(5) = 15. The count grows exponentially.

### Q4

**Short Answer · 4 marks · medium · Apply · CO1 · Unit 2: “counting sort”**

Sort the array [4, 1, 3, 4, 2, 1] with counting sort (values 1 to 4). Show the count array, the cumulative count array, and state the time complexity.


**Model answer:** Counts for 1..4: [2, 1, 1, 2]; cumulative: [2, 3, 4, 6]. Placing elements from right to left gives [1, 1, 2, 3, 4, 4] (stable). Time O(n + k) for n elements and range k.

### Q5

**MCQ · 1 mark · easy · Understand · CO2 · Unit 2: “stable sort”**

Which of these sorting algorithms is NOT stable in its standard implementation?

- (A) Merge sort
- (B) Insertion sort
- (C) Bubble sort
- (D) Quick sort

**Answer:** (D) Quick sort

**Model answer:** Standard partitioning in quick sort can reorder equal keys.

### Q6

**Assertion-Reason · 2 marks · medium · Understand · CO2 · Unit 2: “randomized quick sort”**

Read the assertion and reason about randomized quick sort and choose the correct option.

- **Assertion (A):** Randomized quick sort has expected running time O(n log n) on every input.
- **Reason (R):** Choosing the pivot uniformly at random makes consistently bad splits unlikely, whatever the order of the input.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (A) Both A and R are true, and R is the correct explanation of A

**Model answer:** Both are true, and the random pivot is why the expectation holds for every input.

### Q7

**Long Answer · 8 marks · hard · Evaluate · CO1, CO2 · Unit 2: “Comparison of sorting algorithms on the basis of number of swaps”**

Compare bubble sort, insertion sort, merge sort and heap sort on comparisons, swaps, stability, in-place operation and time complexity. Recommend one for sorting one million nearly sorted records when extra memory is very limited, and justify it.


**Model answer:** Bubble/insertion: O(n^2) worst, stable, in place; insertion is O(n + inversions) on nearly sorted data. Merge: O(n log n), stable, O(n) extra memory. Heap: O(n log n), in place, not stable, few swaps advantage lost. For nearly sorted data with little memory, insertion sort (few inversions, in place) or heap sort if the data may not be nearly sorted; insertion sort is best when inversions are few.

### Q8

**Numerical · 4 marks · medium · Apply · CO5 · Unit 3: “Dijkstra (Greedy Approach)”**

A directed graph has edges A->B (4), A->C (1), C->B (2), B->D (1), C->D (5). Using Dijkstra's algorithm from A, what is the shortest distance to D?


**Answer:** 4

**Model answer:** dist C = 1, B = min(4, 1 + 2) = 3, D = min(3 + 1, 1 + 5) = 4 via A-C-B-D.

### Q9

**Short Answer · 4 marks · medium · Analyze · CO2, CO5 · Unit 3: “Bellman ford (Dynamic Programming)”**

Explain why Dijkstra's algorithm can give wrong answers on graphs with negative edge weights, and how the Bellman-Ford algorithm detects a negative-weight cycle.


**Model answer:** Dijkstra finalises a vertex when it is extracted, assuming later paths cannot be shorter; a negative edge can make them shorter. Bellman-Ford relaxes all edges V - 1 times; if any edge can still be relaxed in a V-th pass, a negative cycle is reachable.

### Q10

**Short Answer · 3 marks · easy · Apply · CO5 · Unit 3: “topological sort”**

Courses A to F have prerequisites A->C, B->C, C->D, B->E, D->F, E->F (X->Y means X before Y). Give a valid order in which to take the courses using topological sort, and state why the graph must be acyclic.


**Model answer:** One order: A, B, C, E, D, F (others are valid). A cycle would make some course its own prerequisite, so no linear order exists.

### Q11

**MCQ · 1 mark · easy · Remember · CO5 · Unit 3: “Kruskal and Prim algorithms”**

What is the time complexity of Kruskal's algorithm using sorting and a union-find structure, for a graph with V vertices and E edges?

- (A) O(V^2)
- (B) O(E log E)
- (C) O(V + E)
- (D) O(E V)

**Answer:** (B) O(E log E)

**Model answer:** Sorting the edges dominates: O(E log E) (= O(E log V)); union-find operations are nearly constant.

### Q12

**Fill in the Blank · 2 marks · easy · Remember · CO2 · Unit 3: “The Floyd Warshall algorithm”**

The Floyd-Warshall algorithm computes all-pairs shortest paths in ___ time and is an example of ___ programming.


**Answer:** blank 1: O(V^3); blank 2: dynamic

**Model answer:** Three nested loops over vertices: O(V^3); it is dynamic programming over intermediate vertices.

### Q13

**Numerical · 3 marks · medium · Apply · CO2 · Unit 4: “Activity selection problem”**

Activities (start, finish): (1,4), (3,5), (0,6), (5,7), (3,9), (5,9), (6,10), (8,11), (8,12), (2,14), (12,16). Using the greedy earliest-finish rule, how many mutually compatible activities are selected?


**Answer:** 4

**Model answer:** Select (1,4), (5,7), (8,11), (12,16): 4 activities.

### Q14

**Numerical · 3 marks · medium · Apply · CO2 · Unit 4: “fractional knapsack problem”**

Knapsack capacity 50. Items (value, weight): (60, 10), (100, 20), (120, 30). What is the maximum value using the fractional knapsack greedy algorithm?


**Answer:** 240

**Model answer:** Ratios 6, 5, 4: take items 1 and 2 fully (160, weight 30), then 20/30 of item 3 (80): total 240.

### Q15

**Long Answer · 8 marks · hard · Apply · CO2 · Unit 4: “Longest common subsequence”**

Using dynamic programming, find the length of the longest common subsequence of X = ABCBDAB and Y = BDCABA, give one LCS, and state the time complexity.


**Model answer:** Fill the (m+1) x (n+1) table with c[i][j] = c[i-1][j-1] + 1 if x_i = y_j else max(c[i-1][j], c[i][j-1]). Length 4; one LCS is BCBA (others: BDAB, BCAB). Time O(mn).

### Q16

**Numerical · 3 marks · medium · Apply · CO2 · Unit 4: “Matrix chain multiplication”**

Matrices A (10 x 30), B (30 x 5) and C (5 x 60) are to be multiplied. What is the minimum number of scalar multiplications needed?


**Answer:** 4500

**Model answer:** (AB)C = 10x30x5 + 10x5x60 = 1500 + 3000 = 4500; A(BC) = 30x5x60 + 10x30x60 = 27000. Minimum 4500.

### Q17

**Short Answer · 4 marks · medium · Analyze · CO6 · Unit 5: “The Rabin-Karp algorithm”**

Explain why the Rabin-Karp algorithm must compare characters after a hash match, and state its expected and worst-case running times for text length n and pattern length m.


**Model answer:** Different strings can share a hash value (spurious hit), so a match must be verified character by character. Expected O(n + m) with a good rolling hash; worst case O(nm) when many spurious hits occur.

### Q18

**Short Answer · 4 marks · medium · Apply · CO6 · Unit 5: “The Knuth-Morris-Pratt algorithm”**

Compute the KMP prefix (failure) function for the pattern ABABCABAB and explain how it avoids re-examining text characters.


**Model answer:** pi = [0, 0, 1, 2, 0, 1, 2, 3, 4]. On a mismatch after matching q characters, the pattern shifts so that pi[q] characters stay matched; the text pointer never moves back, giving O(n + m).

### Q19

**True/False · 1 mark · easy · Understand · CO4 · Unit 5: “The subset-sum problem”**

True or False: Given a proposed subset, we can check in polynomial time whether its elements add up to the target, so the subset-sum problem is in NP.


**Answer:** True

**Model answer:** True: a certificate (the subset) is verified by summing it in polynomial time.

### Q20

**Case Study · 10 marks · hard · Evaluate · CO4, CO5 · Unit 5: “The traveling salesman problem”**

> **Case:** A courier company in Dehradun must plan a daily route for one van that starts at the depot, visits 40 delivery points exactly once and returns, minimising the total distance. Road distances are symmetric and satisfy the triangle inequality.

For the case, explain why an exact optimal route is impractical to guarantee, classify the decision version of the problem, and evaluate a suitable approach the company could use instead.


**Model answer:** This is the travelling salesman problem; its decision version is NP-complete, so no polynomial-time exact algorithm is known and brute force needs (n-1)!/2 tours. With the triangle inequality, an MST-based 2-approximation or Christofides (1.5) gives provable bounds; heuristics such as nearest neighbour plus 2-opt give good routes quickly. Recommend an approximation with local improvement, accepting near-optimal routes.
