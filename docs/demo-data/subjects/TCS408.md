### Q1

**Short Answer · 3 marks · easy · Understand · CO1 · Unit 1: “Concepts of Java Virtual machine (JVM)”**

Explain how the Java Virtual Machine makes compiled Java programs platform independent.


**Model answer:** javac compiles source to platform-neutral bytecode (.class). Each platform has its own JVM that loads, verifies and interprets/JIT-compiles the bytecode, so the same .class file runs anywhere a JVM exists.

### Q2

**MCQ · 2 marks · medium · Analyze · CO1 · Unit 1: “String Handling in java”**

What does this code print? String s1 = "java"; String s2 = new String("java"); System.out.println((s1 == s2) + " " + s1.equals(s2));

- (A) true true
- (B) false true
- (C) true false
- (D) false false

**Answer:** (B) false true

**Model answer:** == compares references (s2 is a new object), equals() compares contents: false true.

### Q3

**Short Answer · 3 marks · medium · Analyze · CO1 · Unit 1: “Scanner Class”**

A program calls sc.nextInt() to read an age and then sc.nextLine() to read a name, but the name is always empty. Explain the cause and give a fix.


**Model answer:** nextInt() reads the number but leaves the newline in the buffer; the next nextLine() returns that empty remainder. Fix: call sc.nextLine() once after nextInt() to consume the newline, or read the age with Integer.parseInt(sc.nextLine()).

### Q4

**Programming · 6 marks · medium · Apply · CO1, CO2 · Unit 1: “constructors”**

Write a Java class BankAccount with fields accountNumber and balance, a no-argument constructor that sets balance to 0, an overloaded constructor taking both values, and methods deposit() and withdraw() that reject invalid amounts.

*Language:* Java

**Model answer:**

```java
public class BankAccount {
    private String accountNumber;
    private double balance;
    public BankAccount() { this("UNASSIGNED", 0); }
    public BankAccount(String no, double bal) { accountNumber = no; balance = bal; }
    public void deposit(double amt) { if (amt <= 0) throw new IllegalArgumentException("amount"); balance += amt; }
    public void withdraw(double amt) { if (amt <= 0 || amt > balance) throw new IllegalArgumentException("amount"); balance -= amt; }
}
```

### Q7

**Assertion-Reason · 2 marks · medium · Analyze · CO2 · Unit 2: “abstract and final classes”**

Read the assertion and reason about abstract and final classes and choose the correct option.

- **Assertion (A):** An abstract class cannot be instantiated.
- **Reason (R):** An abstract class must declare at least one abstract method.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (C) A is true, but R is false

**Model answer:** A is true. R is false: a class can be declared abstract with no abstract methods.

### Q8

**Programming · 6 marks · medium · Apply · CO2 · Unit 2: “Defining Interfaces”**

Define an interface Shape with a method double area(). Implement it in classes Circle and Rectangle, and write main() that stores both in a Shape[] array and prints the total area.

*Language:* Java

**Model answer:**

```java
interface Shape { double area(); }
class Circle implements Shape { double r; Circle(double r) { this.r = r; } public double area() { return Math.PI * r * r; } }
class Rectangle implements Shape { double w, h; Rectangle(double w, double h) { this.w = w; this.h = h; } public double area() { return w * h; } }
// main: Shape[] s = { new Circle(1), new Rectangle(2, 3) }; double t = 0; for (Shape x : s) t += x.area(); System.out.println(t);
```

Explain the visibility of private, default (package), protected and public members to: the same class, another class in the same package, a subclass in another package, and an unrelated class in another package.

### Q11

**Programming · 6 marks · medium · Apply · CO3 · Unit 3: “throw statement, throws clause”**

Define a checked exception InsufficientBalanceException. Write a method withdraw(double amount) that throws it when the balance is too low, and show a caller that handles it with try-catch-finally.

*Language:* Java

**Model answer:**

```java
class InsufficientBalanceException extends Exception {
    InsufficientBalanceException(String m) { super(m); }
}
void withdraw(double amount) throws InsufficientBalanceException {
    if (amount > balance) throw new InsufficientBalanceException("Balance too low");
    balance -= amount;
}
// caller: try { acc.withdraw(500); } catch (InsufficientBalanceException e) { System.out.println(e.getMessage()); } finally { System.out.println("done"); }
```

### Q12

**Long Answer · 8 marks · hard · Create · CO3 · Unit 3: “Producer/ consumer problems”**

Design a bounded buffer of capacity 5 shared by a producer thread and a consumer thread using synchronized methods with wait() and notifyAll(). Explain why the condition is checked in a while loop.


**Model answer:** class Buffer { Queue<Integer> q = new LinkedList<>(); synchronized void put(int x) throws InterruptedException { while (q.size() == 5) wait(); q.add(x); notifyAll(); } synchronized int take() throws InterruptedException { while (q.isEmpty()) wait(); int x = q.remove(); notifyAll(); return x; } }. A while loop re-checks the condition after waking because of spurious wake-ups and because another thread may have changed the state first.

### Q13

**Short Answer · 3 marks · easy · Understand · CO3 · Unit 3: “Byte and Character Streams”**

Distinguish byte streams from character streams in Java and state which you would use to copy an image file and to read a text file containing Hindi text.


**Model answer:** Byte streams (InputStream/OutputStream) move raw 8-bit bytes; character streams (Reader/Writer) handle 16-bit characters with encoding. Image: FileInputStream/FileOutputStream. Hindi text: a Reader with the right charset (e.g. InputStreamReader with UTF-8).

### Q14

**Short Answer · 4 marks · medium · Analyze · CO5 · Unit 4: “Generics”**

Compare a raw List with List<String>: what error does each one catch, and when, if an Integer is added and later cast to String?


**Model answer:** With a raw List the add compiles and the cast fails at run time with ClassCastException. List<String> rejects the add at compile time, so the error is found earlier and no cast is needed (type safety).

### Q16

**Case Study · 10 marks · hard · Evaluate · CO4, CO5 · Unit 4: “ArrayList, LinkedList HashSet and ArrayDeque classes”**

> **Case:** A library system must (1) keep the catalogue so that books can be shown by position on a page, (2) record unique member IDs and check membership quickly, and (3) hold book-return requests that are processed strictly in arrival order, with frequent additions at the end and removals from the front.

For each requirement in the case, choose ArrayList, LinkedList, HashSet or ArrayDeque and justify your choice using the time complexity of the operations involved.


**Model answer:** (1) ArrayList: O(1) indexed access. (2) HashSet: average O(1) add and contains, no duplicates. (3) ArrayDeque used as a queue: O(1) addLast and pollFirst without LinkedList's per-node overhead.

### Q18

**Short Answer · 4 marks · medium · Understand · CO6 · Unit 5: “Event delegation model”**

Explain the event delegation model in Java using a JButton click as an example, naming the source, the event object and the listener.


**Model answer:** The JButton (source) generates an ActionEvent when clicked and delivers it to the objects registered with addActionListener(); each listener implements ActionListener.actionPerformed(ActionEvent). Handling is delegated to the listeners.

### Q20

**Programming · 6 marks · medium · Apply · CO6 · Unit 5: “Creating and executing SQL statements”**

Write Java code using JDBC that inserts a student (roll, name) into a table STUDENT with a PreparedStatement and then prints all rows. Explain why PreparedStatement is safer than building the SQL string by concatenation.

*Language:* Java

**Model answer:**

```java
try (Connection c = DriverManager.getConnection(url, user, pass);
     PreparedStatement ps = c.prepareStatement("INSERT INTO STUDENT(roll, name) VALUES (?, ?)")) {
    ps.setInt(1, roll); ps.setString(2, name); ps.executeUpdate();
    try (Statement st = c.createStatement(); ResultSet rs = st.executeQuery("SELECT roll, name FROM STUDENT")) {
        while (rs.next()) System.out.println(rs.getInt(1) + " " + rs.getString(2));
    }
}
// Parameters are sent separately from the SQL text, so input cannot change the query (prevents SQL injection).
```
