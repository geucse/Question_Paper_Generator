### Q1

**Numerical · 3 marks · medium · Apply · CO1 · Unit 1: “row major and column major form of an array”**

int M[4][6] is stored in row-major order starting at address 1000, with sizeof(int) = 4 bytes. What is the address of M[2][3]?


**Answer:** 1060

**Model answer:** Row-major offset = (2 x 6 + 3) x 4 = 60 bytes; address = 1000 + 60 = 1060.

### Q3

**Programming · 6 marks · medium · Apply · CO1, CO2 · Unit 1: “Multi-Dimensional Arrays”**

Write a C function void transpose(int a[3][3], int t[3][3]) that stores the transpose of a in t, and a main() that prints the transpose of a matrix read from the user.

*Language:* C

**Model answer:**

```c
void transpose(int a[3][3], int t[3][3]) {
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            t[j][i] = a[i][j];
}
/* main: read a[3][3] with nested loops, call transpose(a, t), print t row by row. */
```

### Q5

**Programming · 4 marks · easy · Apply · CO3 · Unit 2: “call by reference”**

Write a C function that swaps two integers in the caller using pointers (call by reference), and show how it is called.

*Language:* C

**Model answer:**

```c
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
/* call: swap(&x, &y); */
```

### Q6

**Short Answer · 4 marks · medium · Analyze · CO3 · Unit 2: “Dynamic memory management in C”**

Compare malloc(), calloc() and realloc(): what each allocates, how memory is initialised, and when you would use each.


**Model answer:** malloc(size) allocates uninitialised bytes; calloc(n, size) allocates n elements and zero-initialises them; realloc(p, size) resizes an existing block, possibly moving it. Use calloc when zeroed memory is needed, realloc to grow a buffer, malloc otherwise.

### Q7

**Assertion-Reason · 2 marks · medium · Analyze · CO3 · Unit 2: “Dangling, Void, Null and Wild pointers”**

Read the assertion and reason about dangling, Void, Null and Wild pointers and choose the correct option.

- **Assertion (A):** After free(p); the pointer p becomes a dangling pointer.
- **Reason (R):** free() sets p to NULL automatically.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (C) A is true, but R is false

**Model answer:** A is true: p still holds the address of released memory. R is false: free() does not change p; the programmer should set p = NULL.

### Q10

**Programming · 6 marks · medium · Apply · CO5 · Unit 3: “counting lines in a text file”**

Write a C program that counts the number of lines in a text file whose name is given by the user, handling the case where the file cannot be opened.

*Language:* C

**Model answer:**

```c
FILE *fp = fopen(name, "r");
if (!fp) { perror("open"); return 1; }
int c, lines = 0;
while ((c = getc(fp)) != EOF)
    if (c == '\n') lines++;
fclose(fp);
printf("%d\n", lines);
```

### Q11

**Short Answer · 4 marks · medium · Understand · CO5 · Unit 3: “Random file accessing methods”**

Explain the roles of fseek(), ftell() and rewind() in random file access, with the meaning of SEEK_SET, SEEK_CUR and SEEK_END.


**Model answer:** fseek(fp, offset, origin) moves the file position relative to SEEK_SET (start), SEEK_CUR (current) or SEEK_END (end); ftell(fp) returns the current position; rewind(fp) returns to the start and clears the error indicator.

### Q18

**Programming · 6 marks · medium · Create · CO2, CO6 · Unit 5: “Handling functions in Python”**

Write a Python function is_prime(n) and use it to print all prime numbers between 1 and 100. Explain why checking divisors up to the square root of n is sufficient.

*Language:* Python

**Model answer:**

```python
def is_prime(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:
        if n % i == 0:
            return False
        i += 1
    return True

print([n for n in range(1, 101) if is_prime(n)])
# A composite n has a factor no larger than sqrt(n).
```

### Q19

**Programming · 4 marks · easy · Apply · CO5, CO6 · Unit 5: “copying one file to another”**

Write a Python program that copies the contents of source.txt to dest.txt line by line using with statements.

*Language:* Python

**Model answer:**

```python
with open('source.txt') as src, open('dest.txt', 'w') as dst:
    for line in src:
        dst.write(line)
```

### Q20

**Case Study · 10 marks · hard · Evaluate · CO2, CO6 · Unit 5: “Control flow”**

> **Case:** An electricity board charges Rs 3 per unit for the first 100 units, Rs 5 per unit for the next 100 units and Rs 8 per unit above 200 units. A clerk enters the units consumed by each of several consumers until a negative value is entered and needs the bill for each.

For the case, propose a Python solution using if-elif-else and loops, and evaluate whether a dictionary of slabs would be a better design than a long if-elif chain.


**Model answer:** Loop reading units until negative; compute bill with if-elif-else on the slabs (e.g. 250 units = 300 + 500 + 400 = 1200). A table of (limit, rate) slabs iterated in a loop is easier to change than hard-coded branches, at the cost of slightly more abstract code; for frequently revised tariffs the table is better.
