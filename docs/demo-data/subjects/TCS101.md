## Course outcomes

- **CO1** — Learn the concepts of IT and understand the fundamentals of basic building blocks of computer science.
- **CO2** — Understand basic data types and syntax of C programming.
- **CO3** — Propose solution to problem by using tools like algorithm and flowcharts.
- **CO4** — Analyze and select the best possible solution for decision- based problems using decision making skills and develop the aptitude to solve iterative problems using different types of looping statements.
- **CO5** — Implement complex problems as a collection of sub problems by applying modularization in applications using functions.
- **CO6** — Apply and implement the concept arrays for providing solution to homogenous collection of data types.

### Q1

**MCQ · 1 mark · easy · Remember · CO1 · Unit 1: “Generation of computers”**

Which switching technology characterises the second generation of computers?

- (A) Vacuum tubes
- (B) Transistors
- (C) Integrated circuits
- (D) Microprocessors

**Answer:** (B) Transistors

**Model answer:** Second-generation computers replaced vacuum tubes with transistors.

### Q2

**Numerical · 2 marks · easy · Apply · CO1 · Unit 1: “bit, byte, KB, MB, GB and their relations to each other”**

A file occupies 3 MB. Using binary prefixes (1 KB = 1024 bytes, 1 MB = 1024 KB), how many bytes does it occupy?


**Answer:** 3145728 bytes

**Model answer:** 3 x 1024 x 1024 = 3,145,728 bytes.

### Q3

**Short Answer · 4 marks · medium · Understand · CO1 · Unit 1: “Computer system memory hierarchy”**

Explain the computer system memory hierarchy from registers to secondary storage, and state how access time, cost per bit and capacity change as one moves down the hierarchy.


**Model answer:** Registers, cache, main memory (RAM), secondary storage (disk/SSD). Moving down: access time increases, cost per bit decreases, capacity increases. Faster, costlier memory is kept small and close to the CPU.

### Q4

**Long Answer · 6 marks · medium · Create · CO3 · Unit 1: “Algorithms and Flow Charts”**

Write an algorithm and draw the corresponding flowchart that reads a positive integer N and prints the sum of its digits. Use a loop and show the decision symbol that terminates it.


**Model answer:** Algorithm: read N; sum = 0; while N > 0: sum = sum + N mod 10, N = N div 10; print sum. Flowchart: start, input N, initialise sum, decision 'N > 0?' (yes: update sum and N, loop back; no: output sum), stop.

### Q6

**Short Answer · 4 marks · medium · Understand · CO2 · Unit 2: “Life of a C program”**

Describe the stages in the life of a C program from source file to execution, naming the output of each stage.


**Model answer:** Preprocessing (expanded source, .i), compilation (assembly, .s), assembly (object code, .o), linking (executable), loading (program placed in memory), execution.

### Q7

**True/False · 1 mark · easy · Understand · CO2 · Unit 2: “Variables and Data types”**

True or False: In C, 'extern int count;' is a declaration that does not allocate storage for count, whereas 'int count = 0;' at file scope is a definition.


**Answer:** True

**Model answer:** True. A declaration introduces the name and type; a definition also allocates storage.

### Q8

**Numerical · 2 marks · medium · Apply · CO2 · Unit 2: “precedence and associativity”**

Using C operator precedence and associativity, what value does x hold after: int x = 10 - 4 / 2 * 3 + 7 % 3;


**Answer:** 5

**Model answer:** 4/2 = 2, 2*3 = 6, 7%3 = 1; 10 - 6 + 1 = 5 (left to right).

### Q9

**Assertion-Reason · 2 marks · medium · Understand · CO2 · Unit 2: “bitwise operators”**

Read the assertion and reason about bitwise operators and choose the correct option.

- **Assertion (A):** For an unsigned int x, the expression x & 1 is 1 exactly when x is odd.
- **Reason (R):** The least significant bit of a binary number is 1 for odd numbers and 0 for even numbers.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (A) Both A and R are true, and R is the correct explanation of A

**Model answer:** Both are true and R explains A: masking with 1 isolates the least significant bit.

### Q10

**Programming · 5 marks · easy · Apply · CO4 · Unit 3: “Conditional statements”**

Write a C program that reads three integers and prints the largest of them using nested if-else statements.

*Language:* C

**Model answer:**

```c
#include <stdio.h>
int main(void) {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);
    if (a >= b) {
        if (a >= c) printf("%d\n", a); else printf("%d\n", c);
    } else {
        if (b >= c) printf("%d\n", b); else printf("%d\n", c);
    }
    return 0;
}
```

### Q11

**Short Answer · 4 marks · medium · Analyze · CO4 · Unit 3: “switch statement”**

A menu-driven program dispatches on an integer choice from 1 to 6. Compare an if-else ladder and a switch statement for this task in terms of readability and execution performance, and state which you would choose.


**Model answer:** switch on a small dense integer range compiles to a jump table (constant time) and reads as a list of cases; an if-else ladder evaluates conditions in sequence. switch is preferred; if-else suits ranges and non-integer conditions.

### Q12

**MCQ · 1 mark · easy · Understand · CO4 · Unit 3: “entry control and exit control”**

Which C loop executes its body at least once even when its condition is false at the start?

- (A) for
- (B) while
- (C) do while
- (D) None of these

**Answer:** (C) do while

**Model answer:** do while is exit-controlled: the condition is tested after the body.

### Q13

**Numerical · 3 marks · medium · Analyze · CO4 · Unit 3: “break and continue”**

What is printed by: int s = 0; for (int i = 1; i <= 10; i++) { if (i % 3 == 0) continue; if (i > 8) break; s += i; } printf("%d", s);


**Answer:** 27

**Model answer:** Adds 1,2,4,5,7,8 (3 and 6 skipped, loop breaks at 9): 1+2+4+5+7+8 = 27.

### Q14

**Long Answer · 8 marks · hard · Evaluate · CO5 · Unit 4: “Recursion v/s Iteration”**

Write recursive and iterative C functions to compute n! and use the function call stack to compare them for memory use and speed. Recommend one for n up to 20 and justify your choice.


**Model answer:** Recursive: return n <= 1 ? 1 : n * fact(n - 1); iterative loop multiplies 2..n. Recursion uses one stack frame per call (O(n) stack) and call overhead; iteration uses O(1) extra space. Use the iterative version (and unsigned long long, since 20! fits in 64 bits).

### Q15

**MCQ · 2 marks · medium · Understand · CO5 · Unit 4: “Storage classes”**

A local variable must keep its value between successive calls of a function. Which storage class should it have?

- (A) auto
- (B) register
- (C) static
- (D) extern

**Answer:** (C) static

**Model answer:** A static local variable has static lifetime but block scope, so it keeps its value between calls.

### Q16

**Short Answer · 3 marks · medium · Analyze · CO5 · Unit 4: “call by value”**

A student writes void swap(int a, int b) { int t = a; a = b; b = t; } and calls swap(x, y), but x and y are unchanged. Explain why, using the call-by-value mechanism.


**Model answer:** C passes copies of the arguments; swap exchanges its local copies a and b, which are destroyed on return, so x and y in the caller are unchanged. Pointers would be needed to modify the caller's variables.

### Q17

**Numerical · 2 marks · medium · Apply · CO6 · Unit 5: “computing address of an element in array”**

An int array A[50] starts at base address 2000 and sizeof(int) is 4 bytes. What is the address of A[17]?


**Answer:** 2068

**Model answer:** Address = base + index x size = 2000 + 17 x 4 = 2068.

### Q18

**Programming · 6 marks · medium · Apply · CO6 · Unit 5: “Searching and Sorting”**

Write a C function int linear_search(int a[], int n, int key) that returns the index of key in a, or -1 if it is absent, and show a call from main for an array of 8 elements.

*Language:* C

**Model answer:**

```c
int linear_search(int a[], int n, int key) {
    for (int i = 0; i < n; i++)
        if (a[i] == key) return i;
    return -1;
}
int main(void) {
    int a[8] = {4, 8, 15, 16, 23, 42, 7, 1};
    printf("%d\n", linear_search(a, 8, 23));
    return 0;
}
```

### Q19

**True/False · 1 mark · easy · Understand · CO6 · Unit 5: “segmentation fault, bound checking”**

True or False: The C compiler checks array bounds at run time and stops the program when an index such as a[10] is used on int a[10].


**Answer:** False

**Model answer:** False. C performs no bound checking; out-of-bounds access is undefined behaviour and may cause a segmentation fault.

### Q20

**Case Study · 10 marks · hard · Create · CO4, CO6 · Unit 5: “Arrays”**

> **Case:** A teacher records the marks (0 to 100) of 30 students in a test and needs a short report: the class average, the highest mark, and the number of students who scored above the average.

Design a C program for the case: read the marks, store them in an array, and print the class average, the highest mark and how many students scored above the average.


**Model answer:** Declare int marks[30]; read with a loop; compute sum and max in one pass; average = sum / 30.0; second pass counts marks[i] > average; print the three results. Validate input range 0-100.
