## Course outcomes

- **CO1** — Understand the process of minimizing Boolean function and obtaining the combinational logic circuits from Boolean functions.
- **CO2** — Analyze the basic storage elements in digital circuits and develop sequential circuits by applying them.
- **CO3** — Evaluate the design of different types of register, counter, and programmable logic devices.
- **CO4** — Apply the concept of digital logic circuits in computer organization & architecture and evaluate the computer performance.
- **CO5** — Create the arithmetic logic used in computer and describe the machine instruction execution.
- **CO6** — Understand the memory hierarchy of computer and how different I/O devices interact with the processing unit.

### Q1

**Short Answer · 5 marks · medium · Apply · CO1 · Unit 1: “K-map method”**

Simplify F(A, B, C, D) = sum of minterms (0, 1, 2, 5, 8, 9, 10) using a Karnaugh map. Show the groups you form.


**Model answer:** Groups: B'C' (0, 1, 8, 9), B'D' (corners 0, 2, 8, 10), A'C'D (1, 5). F = B'C' + B'D' + A'C'D.

### Q2

**Short Answer · 3 marks · easy · Understand · CO1 · Unit 1: “Quine-Mc Clusky method”**

Why is the Quine-McCluskey method preferred over the K-map for functions of six or more variables?


**Model answer:** K-maps become hard to draw and read beyond 4-5 variables and depend on visual grouping; Quine-McCluskey is a tabular, systematic procedure (prime implicants, then a prime implicant chart) that can be programmed.

### Q3

**MCQ · 1 mark · easy · Remember · CO1 · Unit 1: “Nand and Nor Implementation”**

What is the minimum number of 2-input NAND gates needed to implement a 2-input XOR gate?

- (A) 2
- (B) 3
- (C) 4
- (D) 5

**Answer:** (C) 4

**Model answer:** Four NAND gates: N1 = (AB)', then A XOR B = ((A N1)' (B N1)')'.

### Q4

**Short Answer · 4 marks · medium · Apply · CO1 · Unit 1: “Multiplexers”**

Implement F(A, B, C) = sum of minterms (1, 2, 6, 7) with a 4:1 multiplexer using A and B as select lines. Give the four data inputs.


**Model answer:** AB = 00: minterms 0, 1 -> I0 = C. AB = 01: minterms 2, 3 -> I1 = C'. AB = 10: minterms 4, 5 -> I2 = 0. AB = 11: minterms 6, 7 -> I3 = 1.

### Q5

**True/False · 1 mark · easy · Remember · CO2 · Unit 2: “Basic storage elements (Latch and Flip-flops)”**

True or False: In an SR latch built from NOR gates, the input combination S = 1, R = 1 is not allowed.


**Answer:** True

**Model answer:** True: both outputs are forced to 0 and the next state is unpredictable when the inputs return to 0.

### Q6

**Fill in the Blank · 2 marks · easy · Remember · CO2 · Unit 2: “Characteristic equations & tables”**

The characteristic equation of the JK flip-flop is Q(next) = ___, and that of the T flip-flop is Q(next) = ___.


**Answer:** blank 1: JQ' + K'Q; blank 2: T XOR Q

**Model answer:** JK: Q+ = JQ' + K'Q; T: Q+ = T XOR Q.

### Q7

**Short Answer · 4 marks · medium · Apply · CO2 · Unit 2: “Flip-flop conversion”**

Convert a JK flip-flop into a T flip-flop. Show the excitation table you use and the resulting connections.


**Model answer:** T = 0 keeps Q (J = K = 0), T = 1 toggles (J = K = 1). From the excitation tables, J = T and K = T: connect both J and K to T.

### Q8

**Long Answer · 8 marks · hard · Create · CO2 · Unit 2: “Analysis and design of synchronous sequential circuits”**

Design a Mealy sequence detector that outputs 1 when the overlapping sequence 101 is detected on a serial input, using D flip-flops. Give the state diagram, state table and flip-flop input equations.


**Model answer:** States S0 (nothing), S1 (seen 1), S2 (seen 10). S0: 0/0 -> S0, 1/0 -> S1. S1: 0/0 -> S2, 1/0 -> S1. S2: 0/0 -> S0, 1/1 -> S1 (overlap). Encode S0 = 00, S1 = 01, S2 = 10 (Q1Q0): D0 = x, D1 = x' Q0, z = x Q1.

### Q9

**Numerical · 1 mark · easy · Apply · CO3 · Unit 3: “Counters (Ripple & Synchronous): Introduction & Design”**

How many flip-flops are needed to build a mod-12 counter?


**Answer:** 4

**Model answer:** 2^3 = 8 < 12 <= 16 = 2^4, so 4 flip-flops.

### Q10

**Short Answer · 4 marks · medium · Evaluate · CO3 · Unit 3: “Universal shift register”**

A design needs serial-to-parallel conversion, parallel loading and shifting in both directions in one component. Evaluate whether a universal shift register meets this need and describe how its mode-select inputs are used.


**Model answer:** Yes: a universal shift register supports hold, shift left, shift right and parallel load, chosen by two mode-select lines (00 hold, 01 right, 10 left, 11 load) through a 4:1 mux in front of each flip-flop; parallel outputs give serial-to-parallel conversion.

### Q11

**Assertion-Reason · 2 marks · medium · Analyze · CO4 · Unit 3: “RISC and CISC machines”**

Read the assertion and reason about RISC and CISC machines and choose the correct option.

- **Assertion (A):** RISC processors use fixed-length instructions to simplify decoding and pipelining.
- **Reason (R):** RISC processors follow a load/store architecture in which only load and store instructions access memory.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

**Answer:** (B) Both A and R are true, but R is not the correct explanation of A

**Model answer:** Both are true, but load/store access does not explain the use of fixed-length instruction encoding.

### Q12

**Numerical · 3 marks · medium · Apply · CO4 · Unit 3: “Amdahl's Law”**

40% of a program's execution time can be parallelised perfectly. Using Amdahl's law, what is the overall speed-up on 4 processors? (Give two decimal places.)


**Answer:** 1.43 (± 0.01)

**Model answer:** S = 1 / (0.6 + 0.4 / 4) = 1 / 0.7 = 1.43.

### Q13

**Numerical · 3 marks · medium · Apply · CO5 · Unit 4: “Computer Arithmetic (Integer and Floating Point)”**

When 12.375 is stored in IEEE 754 single precision, what is the decimal value of its 8-bit biased exponent field?


**Answer:** 130

**Model answer:** 12.375 = 1100.011 (binary) = 1.100011 x 2^3; biased exponent = 3 + 127 = 130.

### Q14

**MCQ · 1 mark · easy · Understand · CO5 · Unit 4: “Addressing Modes”**

In which addressing mode does the instruction name a register that holds the memory address of the operand?

- (A) Register mode
- (B) Register indirect mode
- (C) Immediate mode
- (D) Direct mode

**Answer:** (B) Register indirect mode

**Model answer:** Register indirect: the register contains the effective address.

### Q15

**Numerical · 2 marks · easy · Apply · CO4, CO5 · Unit 4: “Instruction Pipelining”**

A 5-stage instruction pipeline executes 100 instructions with no stalls. How many clock cycles are needed?


**Answer:** 104

**Model answer:** k + n - 1 = 5 + 100 - 1 = 104 cycles.

### Q16

**Short Answer · 4 marks · medium · Analyze · CO5 · Unit 4: “Hazards”**

For ADD R1, R2, R3 followed by SUB R4, R1, R5 in a 5-stage pipeline, identify the hazard, explain why it occurs, and show how forwarding removes or reduces the stall.


**Model answer:** A RAW data hazard: SUB reads R1 before ADD writes it back. Forwarding passes ADD's ALU result from the EX/MEM latch directly to SUB's ALU input, removing the stall.

### Q17

**Short Answer · 3 marks · easy · Understand · CO6 · Unit 5: “Locality and performance”**

Explain temporal and spatial locality with one programming example of each, and state why locality makes caches effective.


**Model answer:** Temporal: recently used items are used again (a loop counter). Spatial: nearby addresses are used soon (sequential array access). Caches keep recent data and whole blocks, so most accesses hit.

### Q18

**Numerical · 3 marks · medium · Apply · CO6 · Unit 5: “Cache memory”**

A direct-mapped cache of 64 KB has 16-byte blocks and the processor uses 32-bit byte addresses. How many bits are in the tag field?


**Answer:** 16

**Model answer:** Offset 4 bits; 64 KB / 16 B = 4096 lines, index 12 bits; tag = 32 - 12 - 4 = 16 bits.

### Q19

**Numerical · 2 marks · easy · Apply · CO6 · Unit 5: “Cache memory”**

A cache has a hit ratio of 0.9 and an access time of 10 ns; a miss costs the 10 ns cache look-up plus 100 ns to main memory. What is the average memory access time in ns?


**Answer:** 20

**Model answer:** 0.9 x 10 + 0.1 x 110 = 9 + 11 = 20 ns.

### Q20

**Case Study · 10 marks · hard · Evaluate · CO6 · Unit 5: “Direct Memory Access”**

> **Case:** An embedded controller must handle (1) a keyboard producing a few characters per second, (2) a disk transferring 4 KB blocks at high speed, and (3) a temperature sensor read once at start-up during system self-test.

For each device in the case, choose programmed I/O, interrupt-driven I/O or DMA and justify your choice in terms of CPU utilisation and data rate.


**Model answer:** Keyboard: interrupt-driven, as events are rare and polling would waste CPU time. Disk: DMA, so whole blocks move to memory without the CPU handling each word; one interrupt at the end. Sensor at start-up: programmed I/O is simplest, the CPU has nothing else to do and it happens once.
