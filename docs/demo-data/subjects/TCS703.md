## Course outcomes

- **CO1** — Analyze Global and Centralized Routing protocols and utilize tools (such as NS2) to examine routing protocols of LS and DV types
- **CO2** — Evaluate and select the appropriate technology to meet Data Link Layer requirements
- **CO3** — Specify the devices, components and technologies to build a cost- effective LAN
- **CO4** — Appreciate issues for supporting real time and multimedia traffic over public network
- **CO5** — Identify the availability strategies in a Network Management System that will improve network availability and limit the effects of failures
- **CO6** — Implement client server applications with TCP/UDP Socket Programming

### Q1

**Numerical · 4 marks · medium · Apply · CO1 · Unit 1: “The Link State(LS) Routing Algorithm”**

Links and costs: u-v 2, u-x 1, u-w 5, v-x 2, v-w 3, x-w 3, x-y 1, y-w 1, w-z 5, y-z 2. Using Dijkstra's link-state algorithm from u, what is the least cost from u to z?


**Answer:** 4

**Model answer:** u-x 1, x-y 2 (total), y-w 3, y-z 4; the path u-x-y-z costs 1 + 1 + 2 = 4.

### Q2

**Short Answer · 4 marks · medium · Analyze · CO1 · Unit 1: “The Distance Vector (DV) Routing Algorithm”**

Explain the count-to-infinity problem in distance-vector routing after a link cost increases, and how poisoned reverse helps. Does poisoned reverse solve it for all topologies?


**Model answer:** Bad news spreads slowly: two routers keep routing via each other and raise their estimates step by step. With poisoned reverse, a router that routes to a destination via a neighbour advertises infinity to that neighbour, breaking two-node loops. Loops of three or more routers can still count to infinity.

### Q3

**MCQ · 1 mark · easy · Remember · CO1 · Unit 1: “Routing in the Internet: RIP, OSPF, BGP”**

Which protocol is the path-vector protocol used for routing between autonomous systems in the Internet?

- (A) RIP
- (B) OSPF
- (C) BGP
- (D) ARP

**Answer:** (C) BGP

**Model answer:** BGP is the inter-AS path-vector protocol; RIP and OSPF are intra-AS.

### Q4

**Short Answer · 3 marks · easy · Understand · CO1 · Unit 1: “Hierarchical Routing”**

Why does the Internet use hierarchical routing with autonomous systems instead of one flat routing domain?


**Model answer:** Scale (routing tables and update traffic for millions of routers would be impossible) and administrative autonomy (each organisation runs its own intra-AS protocol and policies); gateway routers connect ASes using an inter-AS protocol.

### Q5

**Short Answer · 4 marks · hard · Apply · CO2 · Unit 2: “CRC”**

Data bits D = 101110 are protected with the CRC generator G = 1001. Compute the CRC bits R and the bits actually transmitted.


**Model answer:** Append 3 zeros: 101110000 divided by 1001 (modulo-2) leaves remainder R = 011. Transmitted: 101110011.

### Q6

**Numerical · 2 marks · medium · Apply · CO2 · Unit 2: “Random Access (Slotted Aloha, Aloha, CSMA)”**

For pure ALOHA the throughput is S = G e^(-2G), where G is the offered load in frames per frame time. What is the throughput at G = 0.5? (Three decimal places.)


**Answer:** 0.184 (± 0.002)

**Model answer:** S = 0.5 x e^(-1) = 0.5 x 0.3679 = 0.184 frames per frame time.

### Q7

**Short Answer · 4 marks · medium · Understand · CO2, CO3 · Unit 2: “ARP”**

Explain how ARP lets a host send an IP datagram to another host on the same LAN, and whose MAC address is used when the destination is on a different subnet.


**Model answer:** The host checks its ARP table; if absent it broadcasts an ARP query with the target IP, and the owner replies (unicast) with its MAC, which is cached with a TTL. For a remote destination the frame is addressed to the first-hop router's MAC (found by ARP for the router's IP).

### Q8

- **Reason (R):** Switches operate at the link layer and routers operate at the network layer.
- (A) Both A and R are true, and R is the correct explanation of A
- (B) Both A and R are true, but R is not the correct explanation of A
- (C) A is true, but R is false
- (D) A is false, but R is true

### Q9

**Case Study · 10 marks · hard · Evaluate · CO2, CO3 · Unit 2: “VLANS”**

> **Case:** A college building has three departments (CSE, ECE, administration) spread across four floors, about 300 wired PCs, a server room on the ground floor and one Internet link. Administration data must be isolated from student labs, and the budget is limited.

Propose a cost-effective LAN design for the case, specifying devices, VLANs and how traffic between departments is controlled. Justify your choices against at least one alternative.


**Model answer:** Access switches per floor uplinked to a core layer-3 switch in the server room; VLANs per department (CSE, ECE, Admin, Servers) so one physical network carries isolated broadcast domains; inter-VLAN routing with ACLs on the core switch restricting lab-to-admin traffic; one router/firewall to the Internet. Cheaper than separate physical networks per department and simpler than routers on every floor.

### Q10

**Short Answer · 3 marks · medium · Understand · CO4 · Unit 3: “Streaming Stored Audio and Video”**

Why does a client streaming stored video buffer data before starting playout, and what is the trade-off in choosing the initial playout delay?


**Model answer:** Network delay varies (jitter); a client buffer absorbs it so playout is continuous. A longer initial delay reduces freezes but makes the user wait longer before playback starts.

### Q11

**MCQ · 1 mark · easy · Remember · CO4 · Unit 3: “RTP, RTCP, SIP, H.323”**

Which protocol is used to set up, modify and terminate voice-over-IP calls between users?

- (A) RTP
- (B) RTCP
- (C) SIP
- (D) RTSP

**Answer:** (C) SIP

**Model answer:** SIP is a signalling protocol for establishing and ending sessions; RTP carries the media.

### Q12

**Short Answer · 5 marks · hard · Evaluate · CO4 · Unit 3: “Providing multiple classes of service”**

A university streams live lectures over its campus network, which also carries bulk file downloads. Evaluate overprovisioning the best-effort network against introducing multiple classes of service, and recommend an approach.


**Model answer:** Overprovisioning is simple but costly and fails during unexpected peaks. Classes of service (marking lecture traffic, priority/weighted fair queuing at congested links, policing bulk traffic) protect delay-sensitive video at lower cost but need configuration at every router. Recommend classes of service on the campus routers, keeping reasonable capacity headroom.

### Q13

**True/False · 1 mark · easy · Understand · CO4 · Unit 3: “Real Time Streaming Protocol (RTSP)”**

True or False: RTSP carries the audio and video media data itself.


**Answer:** False

**Model answer:** False. RTSP is an out-of-band control protocol (play, pause, seek); media is carried separately, typically by RTP.

### Q15

**Short Answer · 4 marks · medium · Understand · CO5 · Unit 4: “Infrastructure of Network Management”**

Describe the components of a network management infrastructure: managing entity, managed device, management agent, management information base (MIB) and network management protocol.


**Model answer:** The managing entity (application at the NOC) controls collection and analysis; managed devices contain managed objects; an agent on each device communicates with the managing entity; the MIB holds the objects' data; the protocol (e.g. SNMP) carries queries, settings and traps.

### Q16

**Short Answer · 4 marks · medium · Analyze · CO5 · Unit 4: “The Internet standard Management Framework”**

Explain how polling and traps within the Internet standard management framework can be combined to improve network availability and limit the effects of failures.


**Model answer:** Periodic polling of MIB counters (interface errors, utilisation) reveals trends before failures; traps report sudden events (link down) immediately. Thresholds trigger alerts, so faults are detected and isolated quickly, redundant paths can be activated and capacity planned, reducing downtime.

### Q17

**Programming · 6 marks · medium · Apply · CO6 · Unit 5: “TCP sockets”**

Write the main loop of a concurrent TCP echo server in C using socket(), bind(), listen(), accept() and fork().

*Language:* C

**Model answer:**

```c
int listenfd = socket(AF_INET, SOCK_STREAM, 0);
bind(listenfd, (struct sockaddr *)&servaddr, sizeof servaddr);
listen(listenfd, 10);
for (;;) {
    int connfd = accept(listenfd, NULL, NULL);
    if (fork() == 0) {          /* child */
        close(listenfd);
        char buf[1024]; ssize_t n;
        while ((n = read(connfd, buf, sizeof buf)) > 0) write(connfd, buf, n);
        close(connfd); exit(0);
    }
    close(connfd);              /* parent */
}
```

### Q18

**Programming · 4 marks · easy · Apply · CO6 · Unit 5: “Elementary UDP sockets”**

Write a Python UDP echo client that sends a line typed by the user to a server at 127.0.0.1:9000 and prints the reply, with a 2-second timeout.

*Language:* Python

**Model answer:**

```python
import socket
s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
s.settimeout(2)
s.sendto(input().encode(), ('127.0.0.1', 9000))
try:
    data, _ = s.recvfrom(4096)
    print(data.decode())
except socket.timeout:
    print('no reply')
```

### Q19

**Short Answer · 4 marks · medium · Analyze · CO6 · Unit 5: “lack of flow control with UDP”**

A UDP client sends 2000 datagrams as fast as possible to a slow UDP server. Explain what happens and why, and suggest how the application can cope.


**Model answer:** UDP has no flow control: datagrams arriving when the receive buffer is full are silently dropped, so the server sees far fewer than 2000. The application must add its own pacing, acknowledgements or larger socket buffers, or use TCP.

### Q20

**True/False · 1 mark · easy · Understand · CO6 · Unit 5: “fork and exec function”**

True or False: In a concurrent TCP server, after fork() the child should close the listening socket and the parent should close the connected socket.


**Answer:** True

**Model answer:** True: each process closes the descriptor it does not use, so the connection closes properly when the child finishes.
