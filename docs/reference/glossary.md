# Glossary

| Term | Meaning |
|---|---|
| **Active (question)** | Reviewed, approved and activated; the only state from which questions are selected for papers |
| **Answer key / model answer** | The correct answer and marking guide; printed only on the internal copy |
| **Assertion-Reason** | A question type with an assertion (A), a reason (R) and four fixed options |
| **Audit log** | Tamper-evident record of significant actions, with chain verification |
| **Blueprint** | The rules a paper must meet: difficulty counts, marks, sections, CO and Bloom targets; versioned |
| **Bloom level** | The thinking a question demands: Remember, Understand, Apply, Analyze, Evaluate, Create |
| **Canonical question** | The stable identity of a question across its versions; carries the CO mapping |
| **Candidate copy** | The printed paper given to students (no answers, no analysis) |
| **CO (course outcome)** | A learning outcome of a subject's syllabus (CO1, CO2, …); belongs to one syllabus version |
| **COE** | Controller of Examinations |
| **Course offering** | A subject in a program, session and semester (e.g. TCS 571, B.Tech CSE, 2026-27, semester V) |
| **Feasibility check** | Tells the COE before generation whether the bank can meet a blueprint |
| **HOD** | Head of Department |
| **Internal copy** | The paper with the Paper Analysis page and answer key, for the COE and validators |
| **Internal choice / OR** | "Attempt any k of n"; with k = 1 printed as (a) OR (b) |
| **Override** | An explicit, reasoned COE decision to relax a CO/Bloom target; shown to validators |
| **Paper Analysis** | Page of the internal copy with the distribution by CO, Bloom level, unit and difficulty |
| **Print-ready** | Final, locked state of an approved paper |
| **Quality gate** | The checks a question must pass to become Active |
| **Review batch** | A set of submitted questions the HOD gives to one or more reviewers |
| **Scope** | What an account may act on: campus, department, program or course offering |
| **Seed** | Script that loads demo data (`npm run seed`, `npm run seed:demo`); refused in production |
| **Snapshot** | The frozen copy of a question stored in a generated paper |
| **Syllabus version** | One edition of an offering's official syllabus; Draft → Content verified → In HOD review → Active |
| **TOTP / authenticator** | Time-based codes from an app; required for the COE's final approval |
| **Validator** | One of the four people who independently check a paper before COE approval |
| **Verified topic** | A syllabus topic confirmed by the HOD, worded as in the syllabus |
